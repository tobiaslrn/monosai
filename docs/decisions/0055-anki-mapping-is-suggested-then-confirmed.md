# 0055: Anki mapping is suggested, then confirmed

Status: accepted.

Choosing the first catalogue field can import integers or English while reporting
a successful connection. Desktop AnkiConnect now samples at most eight cards for
each of twenty note types, using only existing validated read operations. Visible
field text is scored by its proportion of Japanese characters. Missing, failed,
or unhelpful samples lead to an explicit choice with no preselected mapping.

The suggested deck, note type, field, and reviewed vocabulary preview stay in
memory. Confirmation commits the source, cache, and combined snapshot in the
existing transaction. Cancellation and navigation store nothing. Existing source
rows collapse their mapping behind Edit. Pasted lists retain mixed input and
report the number of lines without Japanese as an advisory.
