> [!WARNING]
> Monosai is in alpha. Things will break and change while I work on it.

Monosai helps you read Japanese from the very first weeks of learning. Paste any
text to get furigana, word spacing and a built-in dictionary, or have it write
short stories using only the words you've already reviewed in Anki.

I built it while working through a frequency deck and couldn't find anything
simple enough to read. It runs entirely in your browser, works offline once
installed, and only ever reads from Anki. AI features are optional and use your
own OpenRouter key.
